# news-image-20261118 — "Tanker War"

Entry for the make.fun competition news-image-20261118 — "Sum up 18 November's world news in one image" — bounty page: https://make.fun/bounty/news-image-20261118

The image is a newspaper front page dated Wednesday 18 November 2026. Its lead photograph shows an Iranian oil tanker broken in two at the waterline, burning through the night beneath the bow of a US destroyer, under the headline TANKER WAR: overnight the United States sank five Iranian oil tankers, and Tehran struck back at Gulf shipping and at a US base in Jordan. This revision leans harder into that night scene — the fire, the split hull and the destroyer's silhouette now dominate the page, so the lead story reads at a glance before a single column is opened. The rows beneath the lead carry the rest of the day — the Kremlin's vow to rebuild the Kerch Bridge, North Korea's ballistic missile launch, the COP31 climate talks entering their decisive phase, and Nvidia's probe into claims about its own CEO.

## Run

```bash
python3 main.py
```

Running the script writes the bundled `entry.png` to `/output/entry.png` byte for byte and prints the destination path together with the SHA-256 of the delivered file. It uses only the Python standard library, makes no network calls, and is deterministic: every run delivers identical bytes.
